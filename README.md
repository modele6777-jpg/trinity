# TRINITY with Luciel

This contains everything you need to run your app locally.

This application now uses Luciel's tarot counseling prompt with Poe-backed text readings. The existing Trinity interface, account flow, and insight views remain available.

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Create `.env.local` and set your server-only Poe key:
   ```env
   POE_API_KEY=your_new_poe_api_key
   POE_MODEL=GPT-5.4
   ```
   `GEMINI_API_KEY` is optional and is used only for the existing voice playback feature.
3. Run the app:
   `npm run dev`

## Luciel Tarot Integration

- Text counseling calls are proxied by `server.ts` to Poe's Responses API, so the Poe key is not bundled into browser code.
- Tarot draws are generated by the server before interpretation. Daily three-card and quick one-card draws both use the full 78-card deck independently of the user's question.
- Quick one-card readings apply the Luciel prompt in `server/lucielPrompt.ts`, including the randomness notice, reflective guidance, safety boundary, and closing hashtag.
